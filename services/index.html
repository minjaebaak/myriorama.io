보안솔루션 탑재

MYRIORAMA가 만드는 홈페이지에 주식회사 아크링크의 보안솔루션을 함께 탑재합니다.
아래는 아크링크 보안솔루션 가운데 홈페이지와 서버에 쓰는 항목입니다.
탑재할 항목과 범위는 사이트와 호스팅 환경을 보고 상담으로 정합니다.

즉시 제공 01

서버 · 웹 보안 강화

아크링크 서비스의 방화벽 · 접근 통제 · 웹 방화벽 운영 경험을 바탕으로 환경에 맞는 보안 설정을 설계하고, 적용 결과를 검증합니다.

방화벽 기본 차단 정책 허용 대역 제한 웹 방화벽 오탐 조정
즉시 제공 02

부정 접속 분석

홈페이지에 접속 분석 스크립트를 넣어 악성 게시물 작성, 관리자 페이지 반복 접속, 자동화 공격을 분석하고, 같은 브라우저로 보이는 접속을 묶어 보고합니다.

브라우저 지문 봇 · 자동화 접속 판별 부정 클릭 점수화 접속 기록 해시 보존
맞춤 개발 03

이상 행위 감시 · 자동 차단

고객이 수집 · 연동할 수 있는 서버 · 업무 시스템 기록을 대상으로 자료 대량 다운로드, 대량 열람, 반복 접속 시도를 상시 자동 감시하고, 합의한 기준을 넘은 IP를 자동 차단하고 담당자에게 알리는 기능을 맞춤 개발합니다. 감시 대상과 차단 범위는 시험 운영 후 확정합니다.

접속 기록 기준치 감시 반복 접속 시도 IP 자동 차단 담당자 알림
맞춤 개발 04

서버 상시 감시 · 장애 알림

서버와 서비스의 생존, 메모리 · 디스크 압력, 예약작업 변조를 상시 자동 감시하고 이상이 생기면 담당자에게 알리는 구성을 맞춤 개발합니다.

서버 · 웹 서비스 생존 확인 메모리 · 디스크 압력 조기 경보 발송 실패분 재전송
맞춤 개발 05

백업 · 복구 검증

데이터베이스와 업로드 자료를 여러 곳에 나눠 보관하고, 백업이 제때 만들어졌는지와 실제로 복원되는지를 자동으로 확인하는 구성을 맞춤 개발합니다.

서버 밖 별도 장소 사본 백업 신선도 감시 정기 복원 시험

부정 접속 분석은 적용 전에 수집 항목 · 법적 근거 · 보유 기간을 고객과 정하고 개인정보 처리방침에 반영합니다. 관제 인력의 상시 대응이나 보안관제센터 운영 대행은 포함하지 않습니다.
